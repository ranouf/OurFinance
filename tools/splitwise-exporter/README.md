# Aide à l'export Splitwise — cadrage

L'extension Manifest V3 n'est pas encore implémentée. Elle doit seulement aider l'utilisateur à déclencher et récupérer les exports officiellement exposés dans Splitwise Web. Elle ne doit pas utiliser de jetons de session, appeler des endpoints privés ni envoyer automatiquement les fichiers à un tiers. Les formats réellement disponibles doivent être vérifiés avec des fichiers synthétiques avant d'écrire un collecteur ou de promettre un import fidèle.
