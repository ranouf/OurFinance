# M2 — comptes et groupes : état au 18 novembre 2026

Le SDK Firebase Auth et les écrans couvrent l'email/mot de passe, Google, la vérification d'email, la récupération de mot de passe et la déconnexion. Les routes Worker de groupes et invitations, y compris les liens et QR, vérifient le jeton et l'appartenance avant les écritures. Les Firestore Rules interdisent les écritures métier directes du client ; 13 tests Emulator Suite passent sur `main`. La release Rules TEST a été comparée au fichier versionné après le [workflow manuel](https://github.com/ranouf/OurFinance/issues/30#issuecomment-6970237299).

Les essais fictifs sur TEST ont couvert propriétaire, membre actif, tiers et membre révoqué, ainsi que des groupes indépendants CAD/JPY. L'[API des noms de membres](https://github.com/ranouf/OurFinance/issues/133) a été testée puis fusionnée ; son raccordement UI reste ouvert. Le site Hosting principal actuel montre encore brièvement Connexion lors du refresh connecté ([#129](https://github.com/ranouf/OurFinance/issues/129)). Google OAuth et les parcours email externes doivent être rejoués sur le SHA UI final validé visuellement. Le critère M2 complet reste donc ouvert malgré les composants et contrôles serveur déjà opérationnels.
